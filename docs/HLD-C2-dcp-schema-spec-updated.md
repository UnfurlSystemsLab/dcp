# HLD-C2 — DCP Schema Specification (moved)

The authoritative DCP schema specification is
[`unfurl-dcp/docs/HLD-C2-dcp-schema-spec-updated.md`](https://github.com/UnfurlSystemsLab/unfurl-dcp/blob/master/docs/HLD-C2-dcp-schema-spec-updated.md).

This copy used to hold a second version of it. On 2026-11-25 the `unfurl-dcp` copy was made authoritative (HLD-C2
§I.1, divergence #6), so the schema is specified in one place only. Every schema change is made there; this file is kept
only so existing links keep resolving.

The public specification documents in this repository ([`docs/specs/`](specs/)) and the draft machine-readable shapes
([`docs/schemas/`](schemas/)) take their source material from the authoritative copy.
